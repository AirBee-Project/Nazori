3Dモデルデータ（CityGMLなど）を空間IDに変換するツール

説明

1. 変換設定を選んでください（対象・変換方式・フォーマット・ズームレベル）。
2. 対象のXMLファイルを選択、または枠内にドラッグ＆ドロップしてください。
3. 「変換開始」ボタンを押すと処理が始まります。
4. 変換が完了すると、結果ファイルが自動ダウンロードされます。

[変換方式について]

  • Flat: 空間IDのリストのみを高速に抽出します。
  • With Attr: 空間IDと同時に、元の3Dモデルが持つ属性情報を紐付けてJSON形式で出力します。

※データ量が多い場合はブラウザが数秒〜数十秒フリーズすることがあります
